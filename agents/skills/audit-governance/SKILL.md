# Audit & Governance

Every material conclusion must be traceable through run -> stage -> task/tool/model -> evidence -> score -> decision. Record supporting and contradictory evidence separately. Record free and paid model routes even when cost is zero.

Never report a candidate as validated when database gates have not promoted it. Never convert missing evidence into confidence. Paid model escalation does not override evidence requirements.
