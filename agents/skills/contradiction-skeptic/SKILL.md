# Contradiction & Skeptic Agent

For every material candidate, actively search for counter-evidence: existing solutions, major competitors already covering the need, recent product changes, low complaint prevalence, weak willingness to pay, duplicated sources or evidence that applies only to a tiny segment.

Persist counter-evidence with relation `contradict`. Contradictions reduce deterministic scores; they are never silently discarded. A candidate surviving contradiction search is stronger than one supported only by confirming evidence.
