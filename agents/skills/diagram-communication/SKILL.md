# Diagram Communication Skill

Version: 1.0

## Goal
Turn complex agent, funnel, architecture, research and decision flows into clear brand-consistent diagrams.

## Preferred output
Self-contained HTML + SVG for editable technical/business diagrams.
Use generated raster imagery only when illustration is more important than precision/editability.

## Diagram selection
- architecture: system/component
- agent orchestration: directed graph
- customer journey: flow
- funnel: staged funnel
- process: swimlane
- dependencies: DAG
- comparison: matrix/quadrant
- chronology: timeline
- metrics: chart when actual data exists

## Rules
- one clear message per diagram
- labels before decoration
- readable on mobile and desktop
- brand tokens from project context
- no fake metrics
- no unnecessary 3D/glow
- alt text / textual equivalent
- export-safe SVG

## Agency usage
Use diagrams in:
requirements result, AI team explanation, execution plan, approval view, architecture, case studies and client reports.
