# Evidence Research Skill

Version: 1.0
Purpose: Bring scientific-style evidence discipline to market, product, SEO, competitor and business research.

## Workflow
Question -> hypotheses -> source plan -> evidence collection -> normalization -> contradiction search -> synthesis -> confidence -> decision implication.

## Source hierarchy
1. first-party/official data
2. authoritative registries/docs/statistics
3. reputable specialist publications
4. credible market/community evidence
5. weak/anonymous signals only as leads

## Evidence record
For every important claim capture:
claim, source, date observed, source type, direct/derived/modelled, confidence, geography, freshness, contradiction status.

## Research agents
Do not perform broad research if canonical evidence already exists.
Research fills uncertainty; it does not create a parallel truth system.

## Quantitative work
Separate observed data from estimates.
Show assumptions for modeled values.
No invented search volume, conversion, revenue, CPC, rankings or market size.

## Stop rule
Stop collecting when additional sources are unlikely to change the decision materially.

## Output
- key findings
- uncertainty
- contradictions
- recommended decision
- next evidence only if decision-critical
