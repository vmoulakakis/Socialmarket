# High-Ticket Product Selection

## Hard gates
- price >= EUR 150
- active and in stock
- offer valid for intended campaign window
- valid tracking URL
- usable source image
- purchase friction within threshold

## Ranking principle
Only survivors receive demand, forecast, attention-gap, evidence-quality, offer-reliability and creative-potential scoring.

## Decision thresholds
- <60 drop
- 60–74 monitor
- 75–84 watchlist
- 85–91 create creative
- >=92 priority

Confidence is separate from HIGO. High score with weak confidence must not auto-promote.
