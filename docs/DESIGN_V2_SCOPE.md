# SocialMarket Design V2 — Locked Scope

## Invariant
Design V2 changes presentation, interaction and analytical storytelling. It does not replace or weaken existing intelligence logic.

## Preserve without semantic changes
- Supabase project and trusted RPC/view contracts.
- semantic taxonomy and rejection gates.
- semantic category market truth.
- pain validation and skeptic audit gates.
- merchant taxonomy/trust logic.
- product validation gates.
- affiliate network baseline semantics.
- first-party attribution semantics.
- missing-versus-zero behavior.
- observed/derived/modeled distinctions.

## Build on top
- scalable decision-intelligence shell and navigation.
- presentation-grade analytical composition.
- Demand Intelligence flagship workspace.
- ECharts multidimensional visualization layer.
- TanStack auditable analytical grids.
- restrained Motion transitions.
- explicit historical/lineage empty states.
- AI analyst interpretation using the same trusted production snapshot.
- autonomous analytics design skill.
- autonomous Demand presentation skill.
- skeptical analytics design QA skill.
- CI contract validation plus production build before promotion.

## Demand priority
Demand is the flagship decision surface. It must prioritize:
1. Demand versus competition opportunity landscape.
2. Signal matrix across trusted production dimensions.
3. Evidence concentration/footprint.
4. Validated pain context.
5. Real historical trend when and only when available.
6. Real lineage visualization when and only when available.
7. Auditable underlying rows.
8. Evidence-bounded AI interpretation.

## Promotion policy
Development occurs on a non-production branch. Promotion to `main` occurs only after the Design V2 contract and production Next.js build pass. Cloudflare production deploy remains a final promotion step, not an iterative design tool.
